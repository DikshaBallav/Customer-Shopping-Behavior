## 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics and business intelligence project focused on analyzing customer shopping behavior, purchasing patterns, spending, product categories, discounts, subscriptions, and customer demographics.

The project uses Python for data analysis, SQL and PostgreSQL for data querying, and Power BI for interactive visualization and dashboard development.

## 🎯 Project Objectives
-Analyze customer purchasing and spending behavior
-Explore customer demographics and shopping preferences
-Analyze product categories and purchase patterns
-Examine discount and subscription behavior
-Perform business-oriented analysis using SQL
-Build an interactive Power BI dashboard
-Generate insights from customer shopping data

## 📊 Dashboard Preview
-The Power BI dashboard provides an interactive view of customer shopping behavior and helps identify important patterns across purchases, customer segments, product categories, and other behavioral factors.

The analysis helps understand customer purchasing patterns and provides a data-driven view of customer behavior that can support business decisions related to products, customers, discounts, and subscriptions.
